# Improve Codebase Architecture

Find deepening opportunities in a codebase using domain language and ADRs.

## When to use

- Periodically (every few days)
- After major features
- When codebase feels complex

## What it does

Finds opportunities to:
- Deepen modules (small interface, rich implementation)
- Consolidate tightly-coupled code
- Improve testability and AI-navigability

Uses CONTEXT.md vocabulary + respects ADRs.

## Output

HTML report with refactoring suggestions ranked by impact.

See [SKILL.md](./SKILL.md) for deepening criteria.
