# README Section Templates

Standard templates for the 13 sections of a GitHub README.

## Section 1: Badges

```markdown
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Language](https://img.shields.io/badge/Language-Python%203.12+-blue.svg)](https://www.python.org/)
```

## Section 2: Description + Context

```markdown
# Project Name

> Brief tagline (under 120 characters)

Introduction paragraph explaining what, why, and who it's for.
```

## Section 3: Table of Contents

Auto-generated with anchor links to all sections.

## Section 4: Why this project?

Problem statement + solution + differentiators.

## Section 5: Features

Core features, advanced features, upcoming features.

## Section 6: Prerequisites

System requirements, dependencies, accounts needed.

## Section 7: Installation

Multiple options: package manager, from source, Docker.

## Section 8: Usage/Examples

Basic usage + 3-5 common examples with code blocks.

## Section 9: Configuration

Environment variables, config files, .env examples.

## Section 10: Tests

How to run tests, expected output, test structure.

## Section 11: Contributing

How to contribute, coding standards, reporting issues.

## Section 12: License

License type with summary of permissions.

## Section 13: Author

valorisa + GitHub link.
